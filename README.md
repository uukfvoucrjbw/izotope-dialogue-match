## Overview

iZotope Dialogue Match automatically matches the spectral character of ADR or studio-recorded dialogue to on-location production audio using AI spectral analysis.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Izotope Dialogue Match** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **AI Matching** | Automatically analyzes and matches spectral profiles of two clips |
| **Room Tone** | Room acoustics transfer to match on-set to ADR recordings |
| **Reverb Match** | Match and apply room reverb from location audio to ADR |
| **Ambience Match** | Background ambience character matched across production and ADR |
